# StockSense

StockSense is an inventory and stock management application being developed for the Odoo Hackathon 2026.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- Docker
- Git and GitHub

## Project Goal

StockSense aims to help businesses monitor inventory, track stock movements, identify low-stock products, and gain useful insights from inventory data.

## Planned Features

- Inventory dashboard
- Product management
- Stock level tracking
- Stock-in and stock-out tracking
- Low-stock alerts
- Supplier management
- Inventory analytics
- Search and filtering
- Responsive user interface

## Current Status

Initial Next.js and Prisma setup completed.

Database, backend APIs, frontend dashboard, and remaining features are under development.

## Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

The application runs at:

http://localhost:3000
